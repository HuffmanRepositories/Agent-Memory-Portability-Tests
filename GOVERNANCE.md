# Governance

This repository is an independent test corpus. It does not define or endorse a universal agent-memory protocol or schema.

Fixture states: draft (proposed), reviewed (fixture reviewed, not necessarily executed), observed (results recorded for a named system/version), retired (no longer recommended with rationale). A reviewed fixture is not certification.

Observed results should include system/version, date, configuration, and limitations. Discussions should remain evidence-based and respectful.

# Source Baselines and Related Work

This corpus tests cross-cutting migration properties and does not replace existing memory formats/protocols. Treat listed projects as evolving proposals; verify current versions, maturity, and licensing before implementation-specific claims.

- [MacPaw Portable Memory](https://github.com/MacPaw/portable-memory)
- [Portable Agent Memory research](https://arxiv.org/html/2605.11032v1)
- [Open Agent Memory Protocol](https://github.com/deep-thinking-llc/open-agent-memory-protocol)

- [Agent Memory Communication Protocol](https://github.com/nunchi-ai/amcp)

Focus on provenance, scope, retention, deletion, trust, and explicit loss reporting—not duplicating any project's schema.
